These steps use a throwaway `HOME`, so your real `~/notepad` stays untouched.

**Setup**

1. Build the binary and point `HOME` at a temp directory:
   ```sh
   cd /Users/andrew/Projects/notepad
   go build -o /tmp/notepad-bin .
   export HOME=$(mktemp -d)
   export GIT_AUTHOR_NAME=test GIT_AUTHOR_EMAIL=test@example.com GIT_COMMITTER_NAME=test GIT_COMMITTER_EMAIL=test@example.com
   echo $HOME
   ```
   Run all the steps below in this same shell. Run `exit` or open a new terminal afterwards to restore your real `HOME`.

**Usage and version**

2. Run `/tmp/notepad-bin; echo "exit=$?"`. You should see the usage text from `usage.txt` and `exit=1`.
3. Run `/tmp/notepad-bin bogus; echo "exit=$?"` and `/tmp/notepad-bin archive a b; echo "exit=$?"`. Both should print the usage text and exit with 1.
4. Run `/tmp/notepad-bin -v` and `/tmp/notepad-bin --version`. Both should print `0.0.0`.

**Error and empty cases**

5. Run `/tmp/notepad-bin archive; echo "exit=$?"` before `~/notepad/.md` exists. You should see `notepad: open notepad: ... no such file or directory` and `exit=1`.
6. Create an empty notepad and archive it:
   ```sh
   mkdir -p ~/notepad && touch ~/notepad/.md
   /tmp/notepad-bin archive
   ls -a ~/notepad
   ```
   You should see `No notepad contents to archive.`, and `ls` should show only `.md`. No date folder and no `.git` should exist.

**Archive with no title**

7. Archive some content:
   ```sh
   printf 'first note\n' > ~/notepad/.md
   /tmp/notepad-bin archive
   ```
   The output should be `Archived notepad to <HOME>/notepad/<yyyy-mm-dd>/.md`.
8. Verify the results:
   ```sh
   D=$(date +%Y-%m-%d)
   cat ~/notepad/$D/.md        # first note
   wc -c ~/notepad/.md         # 0 (source cleared)
   git -C ~/notepad log --oneline   # 1 commit (empty message)
   git -C ~/notepad status --short  # clean (no output)
   ```

**Same-day append, no title**

9. Archive again on the same day:
   ```sh
   printf 'second note\n' > ~/notepad/.md
   /tmp/notepad-bin archive
   cat ~/notepad/$D/.md
   git -C ~/notepad log --oneline
   ```
   The file should contain both lines (`first note`, then `second note`) and the log should show 2 commits.

**Archive with a title**

10. Archive with a title:
    ```sh
    printf 'my idea\n' > ~/notepad/.md
    /tmp/notepad-bin archive ideas
    ls -a ~/notepad/$D
    cat ~/notepad/$D/ideas.md
    cat ~/notepad/$D/.md
    ```
    `ls` should show `.md` and `ideas.md`. `ideas.md` should contain only `my idea`, and `.md` should be unchanged from step 9.
11. Archive with the same title again:
    ```sh
    printf 'another idea\n' > ~/notepad/.md
    /tmp/notepad-bin archive ideas
    cat ~/notepad/$D/ideas.md
    git -C ~/notepad log --oneline
    ```
    `ideas.md` should contain both ideas, and the log should show 4 commits in total.
12. Confirm the commits contain the archives:
    ```sh
    git -C ~/notepad show --stat HEAD
    ```

**Cleanup**

13. Remove the temp files and restore your shell:
    ```sh
    rm -rf "$HOME" /tmp/notepad-bin
    exit
    ```

**Behaviors to know**

- Entries are appended verbatim, with no separator. If your notepad content doesn't end in a newline, the next archive will run onto the same line.
- Commit messages are intentionally empty (`--allow-empty-message`).
- Your real `~/notepad` currently has a `.git`, an empty `.md`, and an old `2026-10-15T16-39-47.md` from before this design. Running the real binary there will add `<date>/` folders next to it.
